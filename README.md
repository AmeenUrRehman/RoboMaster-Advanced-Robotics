# RoboMaster: Advanced Robotics (SCE 672)

Private repository for the term project assessments (RoboMaster EP, ROS 2 Jazzy, Ubuntu 24.04).

| Folder | Content |
|---|---|
| `Assignment 1` | System provisioning, SDK keyboard teleoperation and telemetry, ROS 2 integration: `ep_teleop_sdk.py`, `rm_setup.sh`, analysis scripts, raw CSV logs and ROS bag, report (`report/report.pdf`) |
| `Assignment 2` | Differential-flatness AprilTag pursuit and motor voltage logging: ROS 2 package `rm_flatness_nav`, `motor_voltage_log.csv`, plots, report (`report/report.pdf`) |

Each assignment folder has its own `README.md` with run instructions.
